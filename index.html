Why Jakarta Language?

A programming language designed for Indonesian developers, by Indonesian developers.

🇮🇩

Indonesian Keywords

Write code using jika, lain, biar, tulis and more — natural and intuitive for Indonesian speakers.

⚡

Runs in Browser

No installation needed. The interpreter runs entirely in your browser — just open and start coding.

🛡️

Safe Execution

Sandboxed environment with execution timeout protection. Experiment freely without risk.

📦

Rich Built-ins

Array methods, string operations, math functions, and type conversions — all built in.

🎨

Modern Syntax

Template literals, arrow functions, destructuring, and spread operators — modern JS features with Indonesian keywords.

Code Examples

                        
Practical examples to get you started with Jakarta Language.

                        

                            

                                

                                    
Hello World

                                    ▸
                                

                                

                                    
tulis("Halo, Dunia!");
tulis("Selamat datang di Jakarta Language!");

                                

                            

                            

                                

                                    
Variables & Types

                                    ▸
                                

                                

                                    
biar nama = "Jakarta";
biar versi = 1.0;
biar aktif = benar;
konstan PI = 3.14159;

tulis(`Nama: ${nama}`);
tulis(`Versi: ${versi}`);
tulis(`Aktif: ${aktif}`);
tulis(`PI: ${PI}`);

                                

                            

                            

                                

                                    
Functions

                                    ▸
                                

                                

                                    
fungsi tambah(a, b) {
    kembali a + b;
}

fungsi faktorial(n) {
    jika (n <= 1) kembali 1;
    kembali n * faktorial(n - 1);
}

tulis(`5 + 3 = ${tambah(5, 3)}`);
tulis(`5! = ${faktorial(5)}`);

                                

                            

                            

                                

                                    
Loops & Conditions

                                    ▸
                                

                                

                                    
untuk (biar i = 1; i <= 5; i += 1) {
    jika (i % 2 == 0) {
        tulis(`${i} adalah genap`);
    } lain {
        tulis(`${i} adalah ganjil`);
    }
}

biar hitung = 0;
selama (hitung < 3) {
    tulis(`Hitung: ${hitung}`);
    hitung += 1;
}

                                

                            

                            

                                

                                    
Arrays

                                    ▸
                                

                                

                                    
biar buah = ["Mangga", "Durian", "Rambutan"];

tulis(`Buah pertama: ${buah[0]}`);
tulis(`Jumlah buah: ${panjang(buah)}`);

buah.dorong("Salak");
tulis(`Setelah dorong: ${buah}`);

biar angka = [5, 3, 8, 1, 9];
biar diurutkan = angka.urutkan((a, b) => a - b);
tulis(`Diurutkan: ${diurutkan}`);
